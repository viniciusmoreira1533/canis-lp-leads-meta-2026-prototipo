# 🐺 Landing Page Protótipo Meta Canis

Protótipo de Landing Page premium e altamente interativo para a marca **Meta Canis**, focada em tráfego pago, funis inteligentes e ultra-performance de vendas com Inteligência Artificial.

## 🎨 Design & Funcionalidades

O projeto foi construído seguindo rigorosamente os padrões visuais da marca Canis:
- **Estética Dark Futurista**: Fundo escuro profundo com efeitos de iluminação e brilho (mesh gradients) usando CSS Vanilla puro.
- **Micro-interações Modernas**: Cursor customizado que segue o mouse, animações de revelação (fade-in) e transições suaves.
- **Dashboard Interativo**: Um painel com gráficos responsivos de desempenho de tráfego e insights.
- **Calculadora ROI Dinâmica**: Simulador instantâneo onde o usuário insere investimento e CPL para obter leads estimadas e retorno (ROAS de 4.5x).
- **Formulário com Borda Conica Animada**: Captura de leads de alta conversão integrada com estados dinâmicos de sucesso.
- **Widget do WhatsApp**: Botão flutuante de contato rápido apontando para o time comercial da Canis.

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**: Estrutura robusta e acessível.
- **CSS Vanilla (puro)**: Customizado com variáveis de estilo e responsividade flexível.
- **Javascript Moderno (ES6+)**: Lógica e efeitos puros sem dependências externas.
- **Vite**: Empacotador e servidor de desenvolvimento leve.

## 🚀 Como Executar

### 1. Instalar as Dependências
Instale o Vite na pasta do projeto:
```bash
npm install
```

### 2. Executar Servidor de Desenvolvimento
Inicie o servidor local para desenvolvimento:
```bash
npm run dev
```

### 3. Compilar para Produção
Gere os arquivos minificados e otimizados na pasta `/dist`:
```bash
npm run build
```
